Multi-Stage Algorithmic Screening Architecture

CORE 01 // SYNTAX & OCR

Multi-Engine OCR & Regex Validation

Deterministic verification of alphanumeric identifiers against official PAN, Aadhaar, and Visa syntax with localized grayscale thresholding and fuzzy Levenshtein name matching.

CORE 02 // COMPRESSION MATRIX

Error Level Analysis (ELA)

Performs 90% recompression delta analysis across 4x4 matrix sectors, isolating compression variance to detect digitally spliced text, pasted headshots, and altered numbers.

CORE 03 // SPATIAL SPLICING

3x3 Laplacian Variance Grid

Spatially partitioned high-frequency gradient inspection flags sharp digital text overlays spliced onto degraded, printed, or low-resolution scanned document surfaces.

CORE 04 // METADATA & GEOMETRY

Aspect Ratio & EXIF Forensic Audit

Measures physical bounding proportions against ISO/IEC 7810 standards (1.586 target ratio) and probes binary image headers for Photoshop, GIMP, or Canva software signatures.
